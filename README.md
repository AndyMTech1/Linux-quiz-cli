# LPI Linux Essentials Terminal Quiz CLI

An interactive Bash command-line quiz built to practice and memorize core commands, directories, and concepts for the **LPI Linux Essentials (010-160)** certification.

## How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd linux-quiz-cli
   ```

2. **Make the script executable:**
   ```bash
   chmod +x quiz.sh
   ```

3. **Run the quiz:**
   ```bash
   ./quiz.sh
   ```

## What It Covers
* **OS Architecture & Kernel Info:** Checking kernel release versions (`uname -r`)
* **Filesystem Hierarchy (FHS):** Identifying key system directories (`/etc`, `/var/log`)
* **Navigation & Listing:** Checking current paths (`pwd`) and viewing hidden files (`ls -la`)

*Updated regularly as I learn new Linux commands and cybersecurity fundamentals.*
